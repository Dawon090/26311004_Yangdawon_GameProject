# ENDURE

# 게임 개요
장르: 탑다운 생존 슈팅
개발 환경: Visual Studio / C++ / GLC2D
플레이 인원: 1인

플레이어가 한정된 전투 공간에서 몰려오는 적을 처치하고 제한 시간 동안 살아남는 게임이다. 일반 적을 처치해 점수와 경험치를 얻고, 능력을 강화하며 마지막에 등장하는 보스를 상대한다.


# 게임 목적
제한 시간 동안 적을 처치하며 생존한 뒤, 마지막에 등장하는 보스를 처치하는 것이 목적이다.


# 조작 방법
W, A, S, D: 캐릭터 이동
Space Bar: 총알 발사
Esc: 일시정지 또는 게임 종료


# 게임 규칙
1. 적은 화면 바깥에서 일정한 시간 간격으로 생성된다.
2. 적은 플레이어를 향해 이동하며, 플레이어에게 공격 또는 플레이어와 충돌 시 피해를 준다.
3. 플레이어의 총알이 적에게 명중하면 적의 체력이 감소한다.
4. 적을 처치하면 점수와 경험치를 획득한다.
5. 경험치가 일정량 쌓이면 능력 하나를 선택하여 강화할 수 있다.
6. 제한 시간이 지나면 보스가 등장한다.


# 점수/승부 규칙
일반 적 처치: 100점
강한 적 처치: 200점
보스 처치: 2,000점
게임 클리어: 추가 1,000점

플레이어가 보스를 처치하면 승리하고, 플레이어의 체력이 0이 되면 패배한다.


# 게임 시작 조건
시작 화면에서 게임 시작 버튼 또는 Enter 키를 누르면 게임이 시작된다. 시작할 때 플레이어의 체력, 점수, 경험치와 제한 시간이 초기화된다.


# 게임 종료 조건
승리 조건: 제한 시간 후 등장하는 보스를 처치한다.
패배 조건: 적과 충돌하거나 공격을 받아 플레이어의 체력이 0이 된다.

게임이 종료되면 최종 점수와 생존 시간을 표시하며, 재시작하거나 게임을 종료할 수 있다.


# 플레이어 기본 정보
플레이어는 전투 공간 안에서 상하좌우로 이동하고 원하는 방향으로 총알을 발사한다. 적의 공격을 피하면서 적을 처치해 경험치를 얻는다. 레벨업 시 능력을 하나 강화할 수 있다.
공격력: 20
체력: 100
공격속도: 0.5s
이동속도: 200px/s
방어력: 0%


# 적 기본 정보
일반 적: 플레이어를 향해 계속 이동하며 접촉 시 피해를 준다.

강한 적: 일반 적보다 체력과 공격력이 높다.

보스: 높은 체력을 가지고 플레이어를 추적하며 주기적으로 탄환을 발사한다.


# 아이템 정보
경험치 아이템: 맵과 적을 처치한 위치에 생성되며, 플레이어가 획득하면 경험치가 증가한다.
회복 포션: 맵에 랜덤으로 생성된다.


# 게임 화면 구성
시작 화면: 게임 제목, 게임 시작, 조작 방법을 표시한다.
플레이 화면: 플레이어, 적, 총알, 배경과 함께 체력, 경험치, 남은 시간, 점수를 표시한다.
강화 선택 화면: 레벨업 시 선택 가능한 강화 세 가지를 표시한다.
결과 화면: 승리 또는 패배 여부, 최종 점수, 생존 시간, 재시작 방법을 표시한다.


# 게임 진행 흐름
시작 화면
→ 게임 시작
→ 플레이어 이동 및 적 공격
→ 적 처치 후 점수와 경험치 획득
→ 레벨업 및 능력 강화
→ 시간이 지날수록 적의 수와 난이도 증가
→ 제한시간 후 보스 등장
→ 보스 처치 시 게임 클리어 / 체력 0일 시 게임오버
→ 결과 확인 후 재시작 또는 종료

# 강화 능력
레벨업 시 공격력, 이동속도, 연사속도, 다중발사, 방어력 중 세가지의 선택지가 주어지며 그 중 하나를 선택해 능력을 강화할 수 있다.

## 강화 능력 1단계
1. 공격력: 피해량 +20%
2. 이동속도: 이속 +10%
3. 연사속도: 발사간격 -15%
4. 다중발사: 총알2발
5. 방어력: 피해감소10%
